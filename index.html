SUMMER VACATION RULES

Simple to learn.
One more round?

This is the three-piece game from the original repository, inspired by games with my nani. It is not standard Nine Men’s Morris.

Place, then move.

Amber starts. Alternate placing one piece on any empty spot. Each player has three. After all six are placed, select one of your pieces, then select any empty spot to move it there. You do not have to move along a line or to a neighboring spot.

Three in a line wins.

A row, column or diagonal wins immediately, including during placement. There are no captures. A round is a draw if the same board and player-to-move repeat three times, or after 200 movement turns. The starting player alternates each round.

Two ways to play.

Same device: take turns on one screen. Online: create a room, copy the link and send it to your friend. The host is Amber; the guest is Forest. Both must press Play again for a rematch. A disconnected player can rejoin without resetting the board while the host tab stays open.

Keyboard: Tab or arrow keys to navigate, Enter or Space to play, Escape to deselect.

NO ACCOUNT. NO GAME SERVER TO RUN.

How online play works.

GitHub Pages serves this website. PeerJS’s public signaling service introduces the browsers; WebRTC carries the game messages. PeerJS 1.5.5 also configures public STUN/TURN services to help with network restrictions.

The connection library is downloaded from jsDelivr (or unpkg as a fallback) only when you create or join a room. These providers and connection services can see normal connection metadata such as your IP address. Your opponent may also learn your IP address through WebRTC. Only join people you trust.

No microphone, camera, login or analytics is used. Same-device progress is saved in your browser. A rejoin token is saved in your tab’s session storage. Room data stays in the host tab’s memory; closing or refreshing that tab ends the room.

Public services have no availability guarantee. Some school, corporate or mobile networks can still block connections. Try a different network if Reconnect does not help. Same-device play does not need the online services.

The host validates moves and both browsers replay the move history. This is a friendly game, not a cheat-proof competitive service. Invitations give access to the guest seat; share them privately.
